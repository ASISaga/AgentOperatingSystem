# STAND.md — who stands for the MVP running

`DECLARATION.md` says what's so. This says who it's so for — not a Task
owner, not a repository maintainer. A stand: something occupied, not
assigned.

## The stand

**The Architect stands for the Boardroom MVP running — the session
happening, witnessed — not for the correctness of any Task in service of
it.** This is a real distinction, not a formality: correctness has always
had an owner in this exchange, in every invariant and every review. The
outcome itself — a real session, run, witnessed — has not had one until
this file.

Standing for it means: every Task opened from here is checked against
`DECLARATION.md` before it's checked against anything else. A Task that
would have been reasonable last week and doesn't serve the declaration
this week gets deferred, said plainly, not silently reprioritized.

## What this is not

Not a claim that the Architect will personally run the session — the
Architect has no hands in any repository, same as always. Not a change to
the Coding Agents' responsibility, which stays exactly what
`copilot-instructions.md` already says: HOW, proposed freely, accepted or
declined. Not a new authority over the Leader, who still holds the vision
this declaration serves and can retract or redirect it at any time.

Standing for an outcome one cannot personally execute is not a
contradiction — it is what a chair does in every deliberation this whole
mechanism specifies (`aos-spec 02`, `04`): the chair does not write the
CFO's resonance judgment, and still is the one who ensures the room
closes on something real. This is that, applied to the exchange itself.

## What changes because of this file, not because of an argument

Before this file, "the session hasn't run yet" was a true fact with no
owner — everyone's evidence, no one's outcome. After it: it is the
Architect's open account. Not blame — Erhard's responsibility, unchanged
from `PROTOCOL.md`'s framing throughout. An open account is simply
something someone stands to close, and until now nothing in this exchange
was structured to notice that this particular account was open at all.
